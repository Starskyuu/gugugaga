# 城市方舟实时搜救控制台（第一版）

这是独立前端工程，不会修改原有 MicroPython 主程序。

## 已保留的控制协议

- 前进：`GET /F`
- 后退：`GET /B`
- 左转：`GET /L`
- 右转：`GET /R`
- 停止：`GET /S`
- 按住方向按钮时每 200ms 重发一次运动指令
- 松手、触控取消、页面失焦或进入后台时发送停车指令

## 第一版功能

- 桌面端、平板和手机响应式控制界面
- 双紧急停车入口
- 指令响应延迟和链路状态提示
- 当前航行方向可视化
- 最近事件记录
- WASD、方向键与空格键控制
- 摄像头、电量位置预留，但不会伪造设备数据
- 可配置树莓派视觉服务地址
- 接入 `/api/status` 实时显示摄像头、YOLO、参考点和目标数量
- 接入 `/video` 显示树莓派 MJPEG 标注画面

## 本地运行

```powershell
npm run dev
```

浏览器打开终端显示的地址（默认是 `http://localhost:3000`）。

在“设备状态”区域输入树莓派地址，例如：

```text
http://192.168.43.10:8080
```

前端会记住该地址，控制请求也会通过树莓派转发到 ESP32。

## 接入说明

控制请求保持为相对地址，因此前端与 ESP32 页面同源部署时会直接使用原有接口。当前工程用于前端开发和预览；最终写回 MicroPython 的 `HTML` 字符串时，需要将页面打包成适合 ESP32 内存限制的单文件版本。
