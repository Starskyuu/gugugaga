# Steps 4–5: Propulsion and Navigation

## 观看

打开 `05_Propulsion_And_Navigation.blend`，默认已选自动航行场景并停在第1帧，按空格播放。

| 场景 | 内容 |
| --- | --- |
| SIM_04_Twin_Propeller_Drive | 12秒双桨测试：前进、滑行减速、差速转弯、再次前进、停桨。默认近景跟随相机，便于观察螺旋桨。 |
| SIM_05_Autonomous_Navigation | 24秒自动绕障：60×60厘米测试水池，三个圆柱障碍，8 mm/s横向水流，保持7厘米模型船尺度。 |
| SIM_05_Collision_Response | 4秒碰撞测试：船以80 mm/s初速撞向圆柱，发生碰撞后速度被接触冲量改变。时间轴标记了首次碰撞。 |

鼠标移到时间轴，Shift+左方向键回到第1帧，再按空格播放。自动航行画面中，黄色线是规划路线，青色线是实际物理轨迹；青色箭头表示水流方向。近看船只可将场景相机切为同场景的 `Follow_Camera`。

## 已实现

- 延续六自由度浮力、重力、水阻与角阻尼计算，船体仍为70×50 mm，空载质量暂定12 g。
- 双电机独立正反转，最大设定转速2600 rpm，0.12秒电机响应时间。
- 桨推力按 `T = ρ Kt D⁴ n |n|` 计算，n为每秒转数，按桨盘浸水比例修正；每个推力在对应桨轴位置作用，产生转向及姿态力矩。
- 两根旋转轴的动画来自同一份转速积分。左右按配对反向旋转显示；推进采用等效桨推力系数，不计算叶片周围流体或真实螺旋桨效率。
- 阻力使用船相对水流的速度，停桨后船仍受水流和阻力影响。
- 船的水平接触外形采用三个重叠圆组成的保守包络，覆盖船体和附件。对竖直圆柱与水池边界计算法向冲量、恢复与切向摩擦，并修正微小穿透；可产生速度和艏向变化。
- A*在包含船体安全间距的地图上规划路线，控制器跟踪航路点，输出双桨推力差。到达目标区域后减速并朝向来流方向；当前不是高精度动态定位系统。

## 验证

`Navigation_Validation_Report.json` 中13项检查通过，包括：同速前进、停桨减速、左右差速转向、无动力随流漂移、圆柱与池壁接触、无接触绕障、终点误差和时间步长对照。

- 默认绕障过程无碰撞，终点误差约13.35 mm，末端速度约1.0 mm/s。
- 独立撞障测试最大单步穿透约0.024 mm，接触后已修正。
- 时间步长减半后，自动航行终点位置差约0.0055 mm。

这些是数值与功能验证；质量、Kt=0.18、阻力等仍为初始估算，没有经过模型船实测标定。

## 修改和重算

参数文件为 `Navigation_Parameters.json`，基础质量和阻尼仍从 `Physics_Parameters.json` 读取。求解器为 `../scripts/05_Propulsion_Navigation_Physics.py`。

在已有工程中修改电机或控制参数后，可在 Blender 文本编辑器运行 `../scripts/05_Recompute_Drive_And_Navigation.py`，它会重新计算、验证并更新轨迹。改变障碍位置、水流示意、起终点或水池大小时，要在新的空白 Blender 会话中先运行该重算脚本生成结果，再运行 `05_Build_Propulsion_Navigation_Demo.py`，生成一致的环境几何。若改变重心，须先重建步骤1—3的船体物理模型。

目前播放的是**物理计算后烘焙的动画**，不是键盘实时遥控。改变数值后需重算，拖动障碍物不会自动更新碰撞和路径。实际RPM较高，在60帧显示下可能出现转动看似缓慢或反向的采样现象，可查看旋转节点的 `rpm` 自定义属性或输出数据核对。
