# Rescue Control Room — Step 8

## 启动和分享

运行 `Builds/ControlRoom/RescueControlRoom.exe`。这是包含第1–8步功能的新版入口；旧版本仍保留。分享时压缩整个 `Builds/ControlRoom` 文件夹，接收方解压后运行 EXE。

Unity 场景为 `Assets/Rescue/Scenes/RescueControlRoom.unity`，版本6000.6.0f1。船体继续按7×5厘米模型尺度计算，救援站位于中心。

## 新界面

顶部显示已送达、在船上、水中人数和模拟时间。正在登船的人仍归水中，正在下船的人仍归船上；只有下船完成才计入 Rescued。

左侧分为三个页面：

- SCENARIO：四种洪水预设、实时水位与流速、漂浮物、0.5/1/2/4倍模拟速度、暂停/复位和报告导出。Apply preset + reset mission 会清空当前任务进度并建立新的报告记录。单独拖动水位/水流滑块则修改当前运行条件，导出会记录参数变化。
- CONTROL：所选船的自动/手动切换、双桨油门、转速、吃水、倾角，以及任务分配开关。
- VIEW：航线、任务归属线、基地屋顶显示开关及相机控制。关闭屋顶仅影响显示，方便观察已获救人员，不移除碰撞结构。

右侧 FLEET 显示各船状态、载荷、预约人数、速度、左右桨RPM和碰撞计数；PEOPLE 显示人员紧急程度、状态和等待时间；EVENTS 显示状态变化及参数修改。面板内容可滚动。

底部显示任务状态、累计平面航程、各船碰撞进入事件的总数和路径规划次数。碰撞事件按每船记录，同一次船间接触可能计入两艘船，不能等同于独立事故数。

## 快捷键

- P：暂停/继续物理；R：复位任务。复位保留当前环境与船只可用性配置。
- Space：自动模式下停止自动驾驶，物理继续；Resume autopilots 重新开启。
- 1–4：选船；手动接管后 W/S/A/D 才控制该船。
- 左键/中键拖动平移，右键拖动旋转，滚轮指向缩放，方向键移动。
- F 聚焦所选船，Home 全景，C 自由/跟随，H 隐藏/显示界面。

倍速是模拟时间倍率。电脑性能不足时，实际墙钟加速可能低于设定倍率；统计和报告中的时间始终为模拟秒，不是现实救援用时。

## 导出报告

SCENARIO 页面点 Export CSV + JSON now 可导出当前结果；默认完成任务后自动导出一次。每次导出都生成独立文件夹，不覆盖旧报告。Open report folder 打开实际保存位置。

默认根目录在 Windows 用户目录的 `AppData/LocalLow/ModelScaleRescue/Model Scale Rescue/RescueReports`。文件包括：

| 文件 | 内容 |
| --- | --- |
| summary.json | 完成状态、人数、时间、初始和当前环境配置、船与人员汇总 |
| boats.csv | 各船航程、最大速度/倾角、碰撞事件、受阻时长、载荷 |
| people.csv | 每人的状态、承运船、登船完成时间、送达时间、水中等待时间 |
| telemetry.csv | 约每模拟秒一条每船的位置、朝向、速度、转速和载荷记录 |
| events.csv | 人员/船状态变化与参数调整记录 |
| README.txt | 单位、缺失值和计数含义 |

数据使用米、秒、千克等SI单位，界面适当换算为毫米和克。-1 表示尚未记录的承运船或时间。载人统计在模拟转移完成时更新；人物转移动画仍是第7步的简化表示。

首次完成任务后，运行统计冻结，便于比较结果；再次复位开始新记录。为了限制长期运行的内存占用，最多保留24000条轨迹样本和2000条事件；超过时丢弃最旧数据，并在 summary.json 中设置 truncated=true。累计统计不因日志截断而清零。

## 验证

`Reports/Step8_Validation_Report.json` 包含静水、街区水流、三船救24人、浅水拒航、强流压力五类场景。前3类要求完整送达；浅水要求不能虚假计入获救；强流为有时间上限的压力检查，允许任务未完成，不能把该检查通过解释成强流下一定能救完。

各场景持续检查人数守恒、每船不超过6人、实际刚体质量与乘员数量一致。报告保留每组的实际人数、用时、碰撞和结果，不隐藏未完成的场景。

`Reports/Step8_Runtime_Report.json` 检查独立程序的完整救援、暂停、复位和实际导出文件内容。`Reports/Runtime_ControlRoom_UI.png` 与 `Runtime_ControlRoom_Complete_UI.png` 是场景截图，不包含控制面板。

## 出舱与自由视角更新

所有人员送达基地后，船先驶到各自舱门外对正点，调整为船头朝外，再用反向推力倒入原来的船舱。船进入靠泊范围、低速停稳后系泊并停桨；四船全部入库后，舱门用 2.5 秒关闭。界面会显示 Aligning、Reversing 和 Docked。总任务完成时间与自动导出现在包含倒船入库及关门过程；获救人数达到 24 时，入库流程仍会继续。R 可重置整轮流程。

开始或按 R 重置后，四艘船位于各自船舱内，舱门关闭。待命 0.8 秒后，四侧双扇舱门用 2.5 秒滑开；开门完成后解缆，船靠双螺旋桨推进直线驶出，再接入自动搜救路径。门关闭期间和禁用船只保持系泊状态。出舱完成后可切换手动驾驶；浅水时显示无法出舱。

场景区域内按住鼠标右键拖动可旋转，俯仰范围为 -89° 至 +89°，支持仰视和俯视。左键或中键拖动平移，滚轮缩放；Home 恢复总览，F 聚焦所选船，C 切换跟随视角，H 隐藏面板。接近水平视角时平移、缩放使用相机平面，避免画面跳动。

本次出舱回归结果保存为 `Reports/Launch_Validation_0.json`（静水）和 `Reports/Launch_Validation_1.json`（街区水流）；旧五场景报告记录的是此前版本。

关闭 Unity 后运行 `Tools/Build_ControlRoom_And_Verify.ps1`，可重建场景、运行场景验证并打包检查。脚本会重建生成的 RescueControlRoom 场景，手工改动前请另存场景。

当前结果仍属于给定模型尺度、简化浮力/阻力和预设流场的验证。质量和水动力参数尚未通过实物水池试验标定，完整救援用时不是现实洪灾救援性能预测。
