## 横向阅读建议

- 做“机构创新”时，优先对照笔记 1、4、5：它们分别展示了运动学构型创新、方案权衡和航天工程验证闭环。
- 做“自主对接”时，对照笔记 2、6：前者依赖人工地标和解析几何，后者引入深度学习与 3D 激光雷达；两篇相隔约 18 年，技术路线演进非常清楚。
- 做“系统工程”时，重点看笔记 3，并把其车队级评价思想用于笔记 4、5 的坡道方案选择。
