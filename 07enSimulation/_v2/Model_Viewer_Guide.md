# Model Viewer

双击 `Builds/ModelViewer/RescueModelViewer.exe`，无需打开 Unity。

- 顶部按钮或数字键 1–4：切换救援船、救援基地、站立小人、坐姿小人。
- 鼠标左键拖动：旋转视角。
- 鼠标右键或中键拖动：平移视角。
- 滚轮：缩放。
- R：恢复当前模型默认视角。
- F11：切换全屏。
- F12 或 Save PNG：保存当前视角的独立模型照片，不包含按钮面板。

照片保存到可执行文件旁的 `Model_Previews` 文件夹，分辨率为 1800 × 1400。
分享给朋友时，请发送整个 `Builds/ModelViewer` 文件夹，不能只发送 EXE。

Unity 场景：`Assets/Rescue/Scenes/ModelViewer.unity`。
此查看器展示现有模型的外观；救援任务仿真请运行原来的 ControlRoom 版本。
