# 海上救援仿真模型

当前为第二阶段实时游戏模型，使用米制单位，整体布置尺寸为 1.2 × 1.2 × 1.2 米。

## 主要对象

- `BaseStation`：中央基站、操作舱、左右泊位、栏杆、系泊与设备结构。
- `RaspberryPi`：独立树莓派占位总成，依附于基站。
- `OverheadCamera`：独立绳索悬挂俯拍相机，不与基站连接，镜头垂直向下且距地面约 1 米。
- `RescueBoat`：封闭式滑行船体、主甲板、驾驶舱、座椅和发动机灰模。
- `Person`：符合当前船体尺度的救生衣人物灰模。

本阶段加入轻量 PBR 材质分区和中型结构细节，不包含外部贴图库或不可控的超高面数。各 FBX 独立导出，便于后续只修改明确指定的对象。
