# 四船协同搜救软件

该目录包含一个可运行的原型系统：中央基站接收顶视视觉坐标，对固定遇险目标进行四船任务分配，使用 A* 绕开障碍并通过 Wi-Fi/TCP 下发航点；船端接收航点、执行差速控制并在失联时自动停机。

首次使用请完整阅读 [操作指南.md](操作指南.md)，并先运行：

```powershell
python -m unittest discover -s tests -v
python start_local_demo.py
```

本地演示会打开实时二维态势图；4 艘虚拟船会沿规划路线运动并逐个完成救援。动态仿真不访问串口、GPIO 或实体电机。

## 交互式搜救小游戏

运行：

```powershell
python rescue_game.py
```

也可以双击 `启动搜救小游戏.bat`。小游戏使用 60 × 60 cm 场地、22 × 15 cm 中央基站和 4 艘 7 × 5 cm 船；可点击放置目标或随机生成 1–1000 人，然后观看四船分配、避障和救援动画。
